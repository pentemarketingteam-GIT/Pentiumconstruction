## 2. Chat is minimal — the LEFT canvas carries everything

- **Chat sidebar:** ultra-short, plain 7th-grade English. One or two sentences,
  never a detailed explanation. No long lists in the chat.
- **Left AI canvas:** all the detail and every list lives here. It re-renders on
  **every** question, suggestion chip and call-to-action button.
- **When a user asks to "list" / "show all" / "full details":** the chat replies
  briefly (e.g. *"Sure — I've put the full list on the left for you"*) and the
  actual list/spec/amenities/blueprints render in the canvas panel.
- Buttons inside the canvas (Book a site visit, Talk to us, View amenities, View
  specs, View blueprints, next/other project) drive both the canvas and a short
  chat acknowledgement.

The AI knows all projects, services, quality process, why-Pentium, go green,
responsible builder, CSR, the 8 FAQs, all three offices/phones/emails, the
24-hour sales promise and home-loan tie-ups. Guardrails: never invent
price/availability/floor-plan/dates; show website status vs RERA record
separately with dates; send live pricing/slots to sales.
